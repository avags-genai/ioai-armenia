# IOAI-Armenia
## IOAI ARMENIAN OFFICIAL PUBLIC GIT REPOSITORY (FAST FOUNDATION)

A curated collection of resources, tasks, solution ideas, and student work for preparation for the **International Olympiad in Artificial Intelligence (IOAI)**.

This repository gathers useful public materials from IOAI-related initiatives, national olympiads, and student preparation programs. It is intended to help students, mentors, and teams explore practical AI problems, study solution approaches, and prepare for future IOAI competitions.

## Unofficial IOAI Solution Ideas

**Resource:** [IOAI Unofficial Solution Ideas](https://ioai-writeup.github.io/)

This website contains unofficial writeups, editorials, and solution ideas for IOAI tasks. It is a helpful reference for understanding different approaches to solving IOAI-style problems, including machine learning, computer vision, natural language processing, and data analysis tasks.

## Polish AI Olympiad Resources

### 3rd Polish AI Olympiad Tasks

**Repository:** [OlimpiadaAI/III-OlimpiadaAI](https://github.com/OlimpiadaAI/III-OlimpiadaAI)

This repository contains tasks from the **3rd Polish Artificial Intelligence Olympiad**. These problems can be used as additional practice for students preparing for IOAI or other AI competitions.

### Polish IOAI Preparation Materials

**Repository:** [OlimpiadaAI/szkolenia](https://github.com/OlimpiadaAI/szkolenia)

This repository contains training materials created for students participating in the Polish AI Olympiad. The materials cover important topics for AI competitions, including Python, data analysis, machine learning, neural networks, computer vision, natural language processing, and large language models.

## Armenian IOAI Preparation Materials

**Repository:** [avags-genai/ioai-armenia](https://github.com/avags-genai/ioai-armenia/tree/GrikStPreviousIOAI)

This branch contains Armenian student solutions and preparation work for the IOAI 2025 tasks.

## Kazakhstan National IOAI 2025 Problems

**Resource:** [Kazakhstan TST on Kaggle](https://www.kaggle.com/competitions/kazakhstan-tst/discussion/586147)

This Kaggle resource contains materials related to the Kazakhstan national selection process for IOAI 2025. It can be useful for students who want to practice with national-level AI olympiad problems and datasets.
